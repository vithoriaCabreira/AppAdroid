# 🎨 App Android - Catálogo de Obras de Arte

Aplicativo Android desenvolvido em **Java** como projeto da disciplina de **Programação para Dispositivos Móveis** da UTFPR.

O objetivo do aplicativo é permitir que o usuário cadastre, visualize e gerencie suas obras de arte favoritas de forma simples e intuitiva.

---

## 📱 Funcionalidades

- Cadastro de obras de arte
- Listagem das obras cadastradas
- Visualização das informações de cada obra
- Interface desenvolvida com componentes nativos do Android
- Persistência de dados
- Navegação entre telas utilizando Activities

---

## 🛠 Tecnologias Utilizadas

- Java
- Android Studio
- Android SDK
- XML
- Gradle

## 🚀 Como executar

### Pré-requisitos

- Android Studio
- JDK 17 ou superior
- Android SDK instalado

### Instalação

1. Clone este repositório

```bash
git clone https://github.com/vithoriaCabreira/AppAdroid.git
```

2. Abra o projeto no Android Studio.

3. Aguarde a sincronização do Gradle.

4. Execute em um emulador ou dispositivo físico.
